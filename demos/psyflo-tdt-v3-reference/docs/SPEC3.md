## What is new in the shell (all already built; do not edit these files)
* **Two big buttons at the top of the panel, always visible: `Scribe` and `Track time`** (`src/scribe.js`, CSS in `src/lauris.css`). Panel tabs stay Notes | Time | Review.
  * **Scribe**: tap → panel opens (if closed), Notes tab shows a live transcript streaming line by line; when the conversation ends Psyflo **types every box of the open form** (amber, with a typing animation) and the panel shows "Filled N boxes · Left for you: …" with **Copy everything**, **What is left** (→ Review tab), Show transcript, Run it again. On a page with no form, the button asks "What are you sitting down for?" (Admission, Intake, Treatment plan, Daily note, Authorization request) and opens that form with the Scribe already running (`?scribe=1`).
  * **Track time**: one tap starts a timer for the child on the page (or asks who), the same button stops it ("Logged 25 min with M.R."). One real second counts as one minute. It writes into `PSY.time` (the Time tab and Lauris Time Tracker read it).
* **`PSY.scribe.register(routeId, handler)`**: a page declares what its Scribe does (see the header comment in `src/scribe.js`): `label`, `pick:{desc, defaultC, route?}` (listed in the chooser), `hint[]`, `lines(params,ctx)` (the scripted conversation `[{t,who,text}]`), `extract(params,ctx)`, `fill(root, values, ctx) → Promise<{filled, left[]}>`, `copyText(root, ctx)`.
* **`PSY.copy(text, toastMsg)`**: clipboard copy with a select-and-copy modal fallback. **`PSY.acts['xs-copy-all']`** calls the handler's `copyText`.
* **`PSY.lf` (src/lf-kit.js): the Lauris form kit.** Describe a form as a schema and get the real "Online Forms Entry" look, persistence, typing fill, Process Form, Preview Form, Review tab and Scribe wiring. **Read the header comment of `src/lf-kit.js` and the working sample `refs/kit/lf-sample.js` first.** Key pieces: `PSY.lf.define`, `PSY.lf.page`, `PSY.lf.mount`, `PSY.lf.scribe`, `PSY.lf.recs`, `PSY.lf.fill`, `PSY.lf.exportText`, `PSY.lf.st(id,c)` (state), `PSY.lf.val`, `PSY.lf.left`. Fields with `human:true` (diagnosis, "meets criteria", anything that is a clinical decision) are never typed by the Scribe; they appear under "Left for you" and as the first **Review** recommendations ("Your decision: …, suggested …"), written only when the clinician taps "Write it in the form". Lauris refuses Process Form while a `req` box is empty (banner "Form not processed. Required boxes are empty: …").
* Removed from the old design: the per-form "Recording" cards with their own Start/Stop in the panel (`l1b-rec-*`). The Scribe button replaces them everywhere.
