## Contracts the lead provides (already in the tree)

- **`ui.hint(iconName, text, { tone, label, href, text: '3', cls })`** (`web/js/ui/hint.js`, CSS `.ui-hint*`). An icon control (24 px minimum target) whose accessible name is the definition (`label` overrides it) and whose visible bubble shows on hover and on keyboard focus (fixed position, so a table scroll region never clips it; Escape hides it). `tone`: `r` danger, `y` warning, `g` success, `b` info, `n` quiet. Pass `href` for an icon link. `o.text` puts a short visible number beside the icon (`ui.hint('clock', 'Notes due', { tone:'y', text:'3' })`). Use it for every icon-only element you add. Do not put more than a sentence in a bubble.
- Icons are `ui.icon(name, size)` from `web/js/ui/util.js` (names there; add a path to that file if you need a new one, one hunk).
- **Keep as visible text** (do not turn into hover-only): maturity chips (Simulated, Pilot, Future, Working marker), anything a person must read to act safely (a deadline's date, "Needs a decision", a refusal reason on a disabled button), and headings. A hover definition is for things that are a label for something already visible or a quiet qualifier: source and verification chips (the chip may become its icon plus hover), the "Clinical text hidden for your role" line, evidence-missing pills, counts like "3 items", status subtitles, secondary lines under a name. When in doubt keep the text and make it shorter.
- Accessibility rules still apply (`test/a11y.mjs`): one h1, 24 px minimum targets, labelled controls, 12 px minimum text, no `title`-only meaning for something a keyboard user needs (use `ui.hint`).
